Live Translation Example

The same descriptive statistics operation across three languages:

📊 Stata
📈 R
🐍 Python
// Stata: Descriptive statistics
use "dataset.dta", clear
summarize age gender income
tabulate gender, missing
bysort gender: summarize income
          
# R: Descriptive statistics
df <- read.csv("dataset.csv")
summary(df[c("age", "gender", "income")])
table(df$gender, useNA = "ifany")
df %>% group_by(gender) %>% summarize(mean_income = mean(income, na.rm = TRUE))
          
# Python: Descriptive statistics
import pandas as pd
df = pd.read_csv("dataset.csv")
df[['age', 'gender', 'income']].describe()
df['gender'].value_counts(dropna=False)
df.groupby('gender')['income'].mean()
